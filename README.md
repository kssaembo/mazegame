# 기억의 미로

초등학교 4~6학년이 이동과 회전 명령을 순서대로 조립하며 문제 해결 절차를 익히는 1:1 교실 게임입니다.

## 교사용 3분 시작 안내

1. 첫 화면에서 **교사로 시작**을 누릅니다.
2. 학급명과 학생 명단을 입력하고 **학급 세션 시작**을 누릅니다.
3. 화면의 학급 코드를 학생들에게 알려 줍니다.
4. 경기장별 QR 코드 또는 링크를 각 태블릿에서 엽니다.
5. 한 태블릿에서 대결할 학생 두 명을 선택하고 번갈아 플레이합니다.

교사 화면을 닫아도 경기장 게임은 계속됩니다. 같은 브라우저에서 다시 교사 화면을 열면 4자리 학급 코드와 로컬 저장 정보로 명단·결과·순위를 복구합니다. 브라우저 데이터를 삭제하거나 다른 교사 기기로 이동하면 로컬 정보는 복구되지 않습니다.

경기 중 이동 데이터는 네트워크로 전송하지 않습니다. 경기장은 시작 상태와 종료 결과만 교사 화면에 보내며, 결과 전송에 실패하면 로컬에 보관하고 8초 간격으로 다시 전송합니다. 교사가 전체 게임을 종료하면 열려 있는 경기장에 종료 메시지를 전달합니다.

## 핵심 규칙

- 일반 턴은 `앞으로 1칸` 명령이 정확히 3개여야 합니다.
- 더블찬스 턴은 정확히 6칸을 이동하며, 학생마다 2회 사용할 수 있습니다.
- 회전은 이동 칸 수에 포함되지 않습니다.
- 숨겨진 벽이나 미로 경계에 부딪히면 즉시 출발점으로 돌아갑니다.
- 목적지에 닿는 순간 남은 명령을 멈추고 승리합니다.

## 개발 명령

- `npm run dev`: 로컬 실행
- `npm run lint`: 타입 검사
- `npm test`: 규칙 단위 테스트
- `npm run build`: 배포 빌드
