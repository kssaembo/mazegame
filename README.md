# 기억의 미로

초등학교 4~6학년이 이동과 회전 명령을 순서대로 조립하며 문제 해결 절차를 익히는 1:1 교실 게임입니다.

## 교사용 3분 시작 안내

1. 첫 화면에서 **교사로 시작**을 누릅니다.
2. 학급명과 학생 명단을 입력하고 **학급 세션 시작**을 누릅니다.
3. 화면의 학급 코드를 학생들에게 알려 줍니다.
4. 학생 두 명 중 한 명은 **경기 만들기**, 다른 한 명은 같은 코드로 **코드로 참가**를 누릅니다.
5. 두 화면에 `연결됨`이 보이면 경기를 시작합니다.

교사 화면을 닫아도 학생 경기는 계속됩니다. 같은 브라우저에서 다시 교사 화면을 열면 저장된 학급 세션과 결과가 복구됩니다.

## 핵심 규칙

- 일반 턴은 `앞으로 1칸` 명령이 정확히 3개여야 합니다.
- 더블찬스 턴은 정확히 6칸을 이동하며, 학생마다 2회 사용할 수 있습니다.
- 회전은 이동 칸 수에 포함되지 않습니다.
- 숨겨진 벽이나 미로 경계에 부딪히면 즉시 출발점으로 돌아갑니다.
- 목적지에 닿는 순간 남은 명령을 멈추고 승리합니다.

## 개발 명령

- `npm run dev`: 로컬 실행
- `npm run lint`: 타입 검사
- `npm test`: 규칙 단위 테스트
- `npm run build`: 배포 빌드
